# Power BI Desktop

Запустите стенд и демо. В Power BI Desktop выберите **Получить данные → PostgreSQL**:

- Сервер: `127.0.0.1:5432` (или POSTGRES_PORT из .env).
- База: `analytics`.
- Режим: Import для небольшого демо; DirectQuery можно исследовать отдельно.
- Аутентификация базы данных: `bank`, пароль POSTGRES_PASSWORD.
- Выберите public.mart_payments_daily, public.mart_customer_activity, public.dim_customer_history.

У локального стенда SSL не настроен. При запросе Encryption Support подтвердите подключение
без шифрования к локальной базе. Шаги подключения описаны в [официальной документации Microsoft](https://learn.microsoft.com/en-us/power-query/connectors/postgresql).
Подключение через 127.0.0.1 из Windows работает при
стандартном пробросе Docker Desktop/WSL2; при изменённой сетевой конфигурации проверьте проброс.

В отчёте обязательно сделайте фильтр валюты. Денежные показатели задавайте Fixed Decimal Number;
не складывайте RUB/USD/EUR. Для дат создайте календарь и связи по payment_date/activity_date.
История SCD имеет несколько строк на клиента: не создавайте неоднозначную связь many-to-many
по customer_id с историей. Для простого отчёта используйте отдельную текущую dimension, для
исторической сегментации — SQL-запрос с соединением по интервалу.

Примеры страниц: оборот и число операций по дням; каналы платежей; IN/OUT клиентов по валютам;
история изменения сегментов. Обновление Import запускайте после успешной публикации.
Power BI является дополнительным потребителем и не участвует в проверках проекта.
